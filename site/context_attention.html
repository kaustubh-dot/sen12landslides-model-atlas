Spatial attention after temporal pooling

Temporal attention first combines the 15 dates. The new block then lets each location look across the pooled 16 × 16 grid.

U-TAE baselineTemporal poolD32 decoder This variantTemporal poolSpatial attentionD32 decoder
  1. Make spatial tokensFlatten 128 × 16 × 16 into 256 tokens with 128 features each.
  2. Attend across the gridAdd fixed row and column position encodings before LayerNorm and Q/K/V projection. Use 4 heads with 32 features each.
  3. Refine each tokenProject to 128 features and add the input token. Apply LayerNorm and a 128 → 256 → 128 feed-forward block with GELU, then add a second residual.
  4. Restore the gridReshape to 128 × 16 × 16 and pass the result to D32.

D32 also receives the usual attention-weighted encoder skip. The skip weights still come from temporal attention.
